# 近三个月的月经量很少，吃大豆异黄酮还有用吗？

> 更新时间：2026-09-16 (UTC+8)

如果是雌激素低导致的月经量少的话可以吃大豆异黄酮，大豆异黄酮中含有大量的雌激素，可以弥补女性的雌激素和缺陷，使月经量正常。但是这种药物主要适合35岁以上的女性。服用并没有什么副作用，能够很好的调节月经量少的症状。但是还是建议最好去正规医院内分泌科或者妇科做相关检查，明确病因然后对症治疗，平时可以多吃大豆、新鲜水果等。

## 月经量少的原因

引起月经量少的原因有很多,如内分泌紊乱、妇科炎症、精神环境的改变、贫血等。所以不能仅仅只靠大豆异黄酮来进行调理，月经量少也可能是气血虚弱引起的，平时可以多吃一些补气血的食物，比如阿胶、红枣、枸杞等食物，都能起到补气血的效果。比较年轻的女生可以用中药调理。在平时一定要注意自己的生活和饮食习惯，在月经期间不要吃生冷的食物。

1、为减肥过度节食

女性的月经与体重和体内脂肪含量关系极大，所以女性应该正视减肥的意义，对于减肥不应该过度而丧失了健康，这样就得不偿失了。

2、作息无度内分泌失调

由于现在生活节奏较快，女性在生活上的压力也在增加，经常熬夜加班或者是追剧等，导致作息不规律、长期处在紧张的情绪下，就可能导致月经量减少。

3、常生闷气心理抑郁

女性在出现生气的情况如果长期选择不发泄出来，从中医的角度讲容易造成肝郁气滞，从而使经量减少。

4、人工流产

人工流产后卵巢一般可在22天内恢复排卵功能，1个月左右月经来潮。但有少数女性在人工流产后出现经期延长、周期长短不一、闭经等，一般在2—3个月后恢复正常。

5、卵巢功能衰退

卵巢的功能直接影响着女性的月经，月经后期，月经量少，现代医学大多认为与卵泡发育不良或无排卵有关，因此，促排卵、强健卵巢功能是治疗月经过少的主要环节。

6、胸部的病变

许多女性会出现经前乳房胀痛但月经量少的情况，对此可千万别轻视，因为出现乳房胀痛等症状，可能是肝郁气滞型，需要疏肝理气，打通血脉，从而达到整体调经的作用。

以上的原因都可能会导致月经量减少，所以服用大豆异黄酮治疗月经量少的前提应该是已经清楚自己月经量少的原因之后再服用，对症下药才可以药到病除，恢复正常的月经情况。
